# Plantilla en Blanco para Desarrollo de Temas Clásicos en WordPress

Esta es una plantilla base minimalista pensada para crear temas clásicos de WordPress desde cero. Incluye la estructura básica de archivos y carpetas necesaria, y está preparada para trabajar con HTML, CSS, PHP y JavaScript sin depender de constructores o frameworks externos.

## 📝 Descripción

La plantilla en blanco proporciona un punto de partida limpio, con estilos y funcionalidades mínimas. Ideal para tener control total sobre la estructura, diseño y lógica de un tema de WordPress. Compatible con funciones estándar del núcleo y personalizable según necesidades.

## 🚀 Tecnologías Utilizadas

- **HTML5** — Estructura semántica del contenido.
- **CSS3** — Estilizado del tema.
- **PHP** — Funciones de WordPress, lógica del servidor y plantillas.
- **JavaScript** — Interactividad y control del DOM.
